# TestOps Copilot Backend

AI-ассистент для автоматизации работы QA-инженеров на базе Cloud.ru AI Agent.

## 📋 Функционал

- ✅ Генерация тест-кейсов в формате Allure TestOps as Code
- ✅ Оптимизация существующих тест-кейсов
- ✅ Валидация тест-кейсов на соответствие стандартам
- ✅ Интеграция с Cloud.ru AI Agent
- ✅ Парсинг OpenAPI спецификаций
- ✅ Пакетная обработка тестов

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd backend

# Создайте виртуальное окружение
python -m venv venv

# Активируйте окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
